A lightweight, fast and fully customizable WordPress theme built for seamless Elementor integration.

== Description ==

Everest Theme is a blazing-fast, minimalist WordPress theme crafted specifically for full compatibility with the Elementor page builder. Developed by Everest Dijital, this theme provides a clean and flexible base for modern, high-performance websites.

Whether you're a beginner or a professional web creator, Everest Theme gives you the freedom to design without limits. It's perfect for agencies, freelancers, or businesses looking for full control over their design with minimal overhead.

The theme is optimized for speed, SEO, and mobile performance. It supports WordPress core features and is ideal for building custom layouts using Elementor. It can be extended easily via child themes or custom plugins.

== Features ==

Ultra-lightweight and fast

Full compatibility with Elementor

Clean and minimal design

SEO optimized structure

Fully responsive and mobile-friendly

RTL support

Translation-ready

Custom logo, menu, header, and footer support
